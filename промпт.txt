Создай конверсионный сайт на Flask

Идея:
"AI-дайджест для новичков" - сайт с карточками про нейросети, Claude Code, первые проекты, промпты и ошибки.

Сделай:
-карточки из файла content.json;
-у каждой карточки: заголовок, описание, ссылка, теги;
-поиск;
-кнопку "Открыть материал";
-8-10 готовых карточек.

Технически:
-Python, Flask, HTML, CSS, JavaScript;
-файлы: app.py, content.json, index.html, style.css, script.js;
-запуск через python app.py;
-сайт должен хорошо выглядеть на телефоне и компьютере;
-код должен быть понятным для новичка.
